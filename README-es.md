- [FBI IC3: fraude de e-mail corporativo](https://go.mymarketing.click/iaesc-fbi-ic3-fraude-de-e-mail-corporati) - Cómo funciona el fraude del correo de un proveedor o de un jefe, descrito por el FBI. `oficial` `gratis`
- [Febraban: alertas de golpes](https://go.mymarketing.click/iaesc-febraban-alertas-de-golpes) - Las alertas de Febraban sobre estafas contra empresas y personas. `oficial` `gratis`

## Etiquetas

Cada ítem indica qué es. Las etiquetas al lado ayudan a elegir: oficial cuando viene de quien define el estándar, código abierto cuando el código está publicado, gratis o de pago según el modelo de uso, API y SDK según la forma de integrar.
