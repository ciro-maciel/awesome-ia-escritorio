- [Awesome Pix](https://go.mymarketing.click/iaesc-lista-pix) - Entegre edenler için Pix: normlar, API'ler, SDK'lar, sağlayıcılar ve araçlar, tek tek kontrol edilmiş.
- [Awesome MCP Brasil](https://go.mymarketing.click/iaesc-lista-mcp-brasil) - Brezilya hizmetleri için MCP sunucuları: açık veriler, CNPJ, vergi, hukuk, finans piyasası, ticaret ve ödemeler.
- [Awesome livros de IA](https://go.mymarketing.click/iaesc-lista-livros-ia) - Portekizce yapay zekâ kitapları: ilk kullanımdan mesleğe, yapanlardan tartışmaya kadar.
- [Awesome ferramentas online](https://go.mymarketing.click/iaesc-lista-ferramentas-online) - Tarayıcıda açılan, kurulum gerektirmeyen ücretsiz araçlar: görsel, PDF, metin, kod, siteler, e-posta, video ve satış.
- [Awesome NF-e](https://go.mymarketing.click/iaesc-lista-nfe) - Entegre edenler için elektronik fatura: resmi portallar, dile göre kütüphaneler, düzenleme API'leri ve MCP sunucuları.
- [Awesome APIs Brasil](https://go.mymarketing.click/iaesc-lista-apis-brasil) - Brezilya açık API'leri: CEP, CNPJ, Merkez Bankası, IBGE, Yasama, Yargı, resmi tatiller ve açık veriler.
- [Awesome Claude Code BR](https://go.mymarketing.click/iaesc-lista-claude-code-br) - Portekizce Claude Code: Brezilya'da hazırlanmış belgeler, kurslar, skill'ler, kurallar, eklentiler ve MCP sunucuları.
