## AIのプライバシー

- [Anthropic: onde mudar o treino](https://go.mymarketing.click/iaesc-anthropic-onde-mudar-o-treino) - Claudeの会話をモデルの学習に使われないようにする方法。 `公式`
- [Google: atividade do Gemini](https://go.mymarketing.click/iaesc-google-atividade-do-gemini) - Geminiのアクティビティ履歴をオフにする方法と、その影響。 `公式`
- [Microsoft: controles de privacidade do Copilot](https://go.mymarketing.click/iaesc-microsoft-controles-de-privacidade) - Copilotのプライバシーと学習に関する設定の場所。 `公式`
- [OpenAI: controles de dados](https://go.mymarketing.click/iaesc-openai-controles-de-dados) - ChatGPTの会話をモデルの学習に使われないようにする方法。 `公式`
- [WhatsApp: privacidade](https://go.mymarketing.click/iaesc-whatsapp-privacidade) - WhatsAppのプライバシーについての説明。Meta AIと会話する場合も含みます。 `公式`

## 事務所に届く詐欺

偽の請求書、口座変更、取引先ではない人からのメール。

- [CERT.br: fascículo golpes](https://go.mymarketing.click/iaesc-cert-br-fasciculo-golpes) - CERT.brのインターネット詐欺に関する冊子。 `公式` `無料`
- [FBI IC3: fraude de e-mail corporativo](https://go.mymarketing.click/iaesc-fbi-ic3-fraude-de-e-mail-corporati) - 取引先や上司になりすますメール詐欺の手口。FBIの解説です。 `公式` `無料`
- [Febraban: alertas de golpes](https://go.mymarketing.click/iaesc-febraban-alertas-de-golpes) - Febrabanによる、企業と個人を狙う詐欺への注意喚起。 `公式` `無料`
- [Ministério da Justiça: sofri um golpe](https://go.mymarketing.click/iaesc-ministerio-da-justica-sofri-um-gol) - 詐欺被害に遭ったあとに何をすべきか。法務省の案内によります。 `公式` `無料`
