- [FBI IC3: fraude de e-mail corporativo](https://go.mymarketing.click/iaesc-fbi-ic3-fraude-de-e-mail-corporati) - Comment fonctionne la fraude par e-mail du fournisseur ou du supérieur, décrite par le FBI. `officiel` `gratuit`
- [Febraban: alertas de golpes](https://go.mymarketing.click/iaesc-febraban-alertas-de-golpes) - Les alertes de la Febraban sur les arnaques visant les entreprises et les particuliers. `officiel` `gratuit`

## Étiquettes

Chaque élément indique ce qu'il est. Les étiquettes à côté aident à choisir : officiel quand ça vient de l'organisme qui fixe la norme, open source quand le code est publié, gratuit ou payant selon le modèle d'utilisation, API et SDK selon la façon de l'intégrer. Les éléments avec l'étiquette « de l'auteur » sont faits par Ciro Cesar Maciel et suivent les mêmes règles que tous les autres.
