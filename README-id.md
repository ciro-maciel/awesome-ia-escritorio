## Label

Setiap item menjelaskan apa dirinya. Label di sampingnya membantu memilih: resmi jika berasal dari pihak yang membuat standar, open source jika kodenya dipublikasikan, gratis atau berbayar menurut model penggunaannya, serta API dan SDK menurut cara integrasinya. Item dengan label "buatan penulis" dibuat oleh Ciro Cesar Maciel dan mengikuti aturan yang sama dengan item lainnya.
