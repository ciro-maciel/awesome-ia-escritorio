## Метки

Каждый пункт объясняет, что это такое. Метки рядом помогают выбрать: «официальный» — когда инструмент выпущен тем, кто задаёт стандарт, «открытый код» — когда код опубликован, «бесплатный» или «платный» — по модели использования, API и SDK — по способу интеграции. Пункты с меткой «от автора» созданы Сирo Сесаром Масиэлом и подчиняются тем же правилам, что и все остальные.
